CyberVerse Build Report — 2026

Cyber Network Raid — Browser Game

How It Works

  • SVG network map: edge → internal → core layers
  • Click nodes to select them
  • Scan (−1 energy) — reveals service, ports, weakness
  • Exploit (−2 energy) — succeeds based on security level
  • Goal: access all nodes before energy runs out
  • 90-second timer per level
  • 8 levels with escalating difficulty
  • Per-level high scores in localStorage

Technical Details

  • Pure game logic in lib/game/network.ts
  • Deterministic seeded RNG for testing
  • 10 unit tests covering scan/exploit/win/lose
  • Client component: CyberNetworkGame.tsx
  • Page: /game with terminal-style HUD
  • Linked from landing page nav
  • Ethical sandbox framing throughout
  • No external game dependencies

Quickstart

Backend

cd backend
pip install -r requirements.txt
cp .env.example .env
# edit DATABASE_URL, secrets
alembic upgrade head
python scripts/seed.py
uvicorn app.main:app --reload

Frontend

cd frontend
npm install
npm run dev
# → http://localhost:3000

Docker: docker compose -f docker/docker-compose.dev.yml up -d postgres redis

Tests: pytest (backend) · npm test (frontend) · npm run typecheck · npm run lint

Repo: github.com/ashrafhacker/CyberVerse
